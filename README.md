# Pioneer
RRB Station Master 2026 preparation dashboard. Local browser storage only.

## Deploy / update
Upload `index.html`, `manifest.json`, `sw.js`, and `icon.svg` to the root of your GitHub Pages repository. Commit the changes to `main`. GitHub Pages will redeploy automatically.

## Local data
Records are stored in browser localStorage and are not sent to GitHub. Export JSON backups regularly. Clearing site data can erase records.

## Initial data
Study log starts with 2 hours on 2026-11-08. Exam date defaults to 2027-02-10 and target score to 99. Subject totals start at 25 Maths, 9 Basic Science, 35 Reasoning and 12 Data Analysis; completed counts start at zero.
